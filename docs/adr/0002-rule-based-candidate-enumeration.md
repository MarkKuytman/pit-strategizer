# Candidates enumerated by rule, never pre-filtered by the simulator

A scenario's candidate set is generated by bounded legal enumeration (at most two stops, pit laps on a coarse grid) and the ground-truth simulator is used only to score the outcome, never to select or order the options Jev sees. Pre-filtering candidates with the simulator would leak the answer into the input and make a low time lost meaningless. This is a deliberate deviation from the obvious path: a later reader will be tempted to "optimise" by pre-ranking candidates with the simulator, which would silently destroy the experiment.
